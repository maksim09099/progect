# MVP backlog и критерии приемки

## Эпик 1. ЛК районного врача

### User story
Как районный офтальмолог, я хочу вести пациентов и видеть их статус готовности, чтобы заранее доводить пациента до требований стационара.

### Задачи
- Авторизация и роль `DISTRICT_DOCTOR`.
- Dashboard: фильтр/поиск по пациентам.
- Цветовые статусы: `RED`, `YELLOW`, `GREEN`.
- Карточка пациента: паспорт, СНИЛС, полис, МКБ-10.

### Критерии приемки
- Врач видит только «своих» пациентов.
- Статус пациента обновляется при изменении чек-листа.

## Эпик 2. Интерактивный чек-лист

### User story
Как врач, я хочу выполнять стандартизированный протокол по типу операции, чтобы снизить риск пропуска обязательных анализов.

### Задачи
- Шаблоны чек-листа по типам операций.
- Пункты с обязательными файлами.
- Валидация обязательных полей.

### Критерии приемки
- Нельзя отправить пациента хирургу при незаполненных обязательных пунктах.

## Эпик 3. ИОЛ-калькулятор

### User story
Как врач, я хочу автоматически рассчитывать рекомендованную ИОЛ, чтобы уменьшить ошибки ручных вычислений.

### Задачи
- Форма параметров глаза.
- Расчет по минимум двум формулам.
- Сохранение результатов в карточку.

### Критерии приемки
- Для одинакового набора входных данных расчет детерминирован и покрыт тестами.

## Эпик 4. Кабинет хирурга

### User story
Как хирург, я хочу быстро видеть «очередь на подтверждение», чтобы оперативно назначать даты операций.

### Задачи
- Лента пациентов всех районов.
- Просмотр документов и снимков.
- Комментарий на доработку.
- Кнопка «Подтвердить готовность» + дата операции.

### Критерии приемки
- Любое решение хирурга логируется в аудит.

## Эпик 5. Пациентский интерфейс и уведомления

### User story
Как пациент, я хочу понимать свой этап и дату операции, чтобы не ездить в центр без необходимости.

### Задачи
- Страница статуса по short-code.
- Telegram-уведомления (заглушка адаптера).

### Критерии приемки
- Пациент видит только минимально необходимую информацию и не имеет доступа к чужим данным.

## Эпик 6. Offline-first

### User story
Как врач в районе, я хочу заполнять формы без стабильного интернета, чтобы не терять данные.

### Задачи
- Локальное хранение черновиков.
- Очередь синхронизации.
- Индикатор «данные отправлены/ожидают отправки».

### Критерии приемки
- После восстановления сети данные из очереди отправляются автоматически и в корректном порядке.
