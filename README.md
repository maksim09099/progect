# Окулус‑Фельдшер

Веб‑прототип цифровой платформы для удаленной подготовки пациентов к офтальмологическим операциям.

## Что есть в репозитории

- Полноценный адаптивный веб‑сайт (`index.html`, `styles.css`, `app.js`) с современным медицинским UI.
- Демонстрация модулей: роли, дашборд врача, чек‑лист подготовки, пациентский статус.
- Интерактивный ИОЛ‑калькулятор (SRK/T‑like + Haigis‑like, демонстрационная версия).
- Оффлайн‑черновики чек‑листа через `localStorage`.
- PWA‑база: `manifest.webmanifest` + `sw.js` (кеш основных статических ресурсов).
- Документация по архитектуре и MVP backlog в `docs/`.
- Референсный backend‑модуль с тестами для логики ИОЛ (`backend/`).

## Быстрый запуск сайта

```bash
python3 -m http.server 4173
```

Открыть в браузере: `http://localhost:4173`

## Проверка Python-тестов

```bash
python3 -m unittest discover -s backend/tests -v
```

## Важно

Калькулятор ИОЛ в UI и в backend — **демонстрационный прототип** для MVP.
Для клинического применения требуется отдельная медицинская валидация и регуляторное соответствие.
