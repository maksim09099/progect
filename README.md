# Окулус‑Фельдшер (MVP-концепт)

Цифровая платформа для удаленной подготовки пациентов к офтальмологическим операциям между районным звеном и областным стационаром.

## Что реализовано в этом репозитории

- Технический дизайн MVP (роли, модули, потоки, ограничения оффлайн-режима).
- Проектирование архитектуры и интеграционных точек (ЕМИАС/РИАМС как заглушки).
- Базовая доменная модель данных с заделом под HL7/FHIR-совместимость.
- Референсная реализация калькулятора ИОЛ (SRK/T-приближение и Haigis-подобная модель) в Python.
- Юнит-тесты для критичной медицинской логики расчета ИОЛ.

## Роли

1. **Районный офтальмолог/фельдшер** — ведет карточку пациента, чек-лист, загружает документы и снимки.
2. **Хирург-куратор** — валидирует готовность, оставляет комментарии, подтверждает дату операции.
3. **Пациент** — видит ограниченный статус подготовки и дату госпитализации.

## MVP-модули

- ЛК районного врача (dashboard + карточка пациента).
- Интерактивный протокол предоперационной подготовки.
- Загрузка мультимедиа и документов.
- Кабинет хирурга с модерацией.
- Упрощенный пациентский интерфейс + уведомления.

Подробности: `docs/architecture.md` и `docs/mvp-backlog.md`.
